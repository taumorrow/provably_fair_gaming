## S4. Invocation and what the engine prints

Queries: `printf 'set charvar off\n<query>\n' | tau --block-max-splits 1 -b false` — the answer is the line `%1: T` (valid) or `%1: F` (not valid).
Runs: the file holds `set charvar off`, the specification of S1 on one line, then one decimal value per line in the order of the input streams, round by round, and ends with an empty line;
`tau --block-max-splits 1 -b false < file`. The engine prints one line `name[t] := value` per output stream and time point; the line group of time point 0 holds the initial
conditions and precedes the first input; the run ends at the end of the input. Bit-vector arithmetic is modular (default mode); a shift keeps eight bits.
No environment variable of the engine is set for the command line. Through the in-process host the origin (time point 0) arrives without a step request and request k feeds time point k.

## S5. The games

A game is determined by its seed and the version of the specification: contributions are drawn uniformly from 0..255 by Python's `random.Random(seed)`, in the order
contribution of player 0..3 (then the operator's, where the version has one), and each player moves a uniformly drawn piece among those not yet at the goal (in the run with
piece choices outside the range: a value from 0..255); the game ends at the first round in which a win flag is set. Seeds used: 20261001 (six versions), 1–5 (two versions), 7 (range run).
The reference model is part of the generator program, written by the author; it computes the same round function in 8-bit arithmetic.
